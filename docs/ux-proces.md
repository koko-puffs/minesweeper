# UX-proces

## 1. Konventioner (desk research)

Jeg har sammenlignet det klassiske minesweeper på windows:

- minetæller og ur over brættet
- en knap til nyt spil (smiley)
- venstreklik for at afdække og højreklik for at sætte flag
- valg af sværhedsgrad

Ingen af dem gemmer en personlig rekordliste knyttet til en bruger.

## 2. Hypoteser

1. Nye spillere ved ikke, at man sætter flag med højreklik.
2. Det er frustrerende at tabe på første klik.
3. Spillere motiveres af at slå deres egen rekord.
4. En nedtælling gør spillet mere spændende.

## 3. User need statements

- En ny spiller har brug for at se, hvordan man sætter flag, fordi højreklik er skjult.
- En tilbagevendende spiller har brug for at se sine bedste tider.

## 4. Top-opgaver

1. Start et spil
2. Vælg sværhedsgrad og tidsgrænse
3. Opret bruger eller log ind
4. Se mine 3 bedste tider

## 5. Sitemap

Spillet er én side, så alle top-opgaver kan løses uden at skifte side:

- **1.0 Spil**
  - 1.1 Indstillinger (sværhedsgrad, tidsgrænse, nyt spil)
  - 1.2 Brættet (minetæller, smiley, ur, nedtælling)
  - 1.3 Spiller (log ind / opret bruger, 3 bedste tider)
