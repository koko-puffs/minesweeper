# Minesweeper

Minesweeper i browseren med en Node server. Man kan oprette en bruger, vælge sværhedsgrad og tidsgrænse, og gemme sin score på serveren.

## Kør spillet

1. Installer Node.js
2. Kør `node server.js` i mappen
3. Åbn http://localhost:3000
